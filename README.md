# Nook

**Nook** — настраиваемый лаунчер для Windows: соберите приложения, игры, файлы и папки в одном окне, организуйте их по категориям и открывайте с помощью мыши или клавиатуры. Приложение может работать в системном трее и вызываться глобальной горячей клавишей.

> Имя репозитория и проекта сборки — `FastPush`; название приложения — **Nook**.

## Возможности

- Запуск приложений, игр, ярлыков, файлов, внешних ссылок и папок.
- Категории для организации плиток; изменение порядка категорий и плиток.
- Вложенные папки Nook для дополнительной группировки.
- Глобальный поиск по локальному индексу Windows Search и приложениям меню «Пуск».
- Навигация по плиткам клавишами со стрелками и запуск клавишей **Enter**.
- Несколько профилей с независимыми категориями, содержимым плиток, расположением в сетке и оформлением.
- Проверка всех локальных путей и интерактивное исправление ссылок на перемещённые файлы и папки.
- Темы, акцентные цвета, прозрачность, размеры плиток и анимированные фоны.
- Глобальная горячая клавиша, системный трей и необязательный запуск вместе с Windows.
- Импорт и экспорт конфигурации в формате JSON.
- Быстрые действия для Проводника, Параметров Windows, Диспетчера задач и Корзины.

## Начало работы

1. Установите Nook из установщика в разделе [Releases](https://github.com/erray2nova/FastPush/releases) или соберите приложение по инструкции ниже.
2. Откройте Nook. При необходимости нажмите кнопку редактирования **«✎ Ред.»**.
3. Добавьте плитки и категории, либо щёлкните правой кнопкой мыши по плитке и выберите **«Изменить название / исправить путь...»**.
4. Нажмите кнопку настроек, чтобы выбрать оформление, горячую клавишу и поведение окна.
5. Создайте профили для разных наборов приложений или сценариев работы в разделе **Настройки → Другое → Профили раскладки**.

В режиме редактирования окно остаётся доступным при переключении в другие программы. Обычный щелчок по плитке в этом режиме открывает её редактирование; для запуска воспользуйтесь пунктом **«Открыть»** в контекстном меню.

## Плитки, категории и вложенные папки

### Типы плиток

Nook поддерживает:

- приложения и игры, в том числе ярлыки Windows;
- отдельные файлы;
- системные и пользовательские папки;
- ссылки и URI, если в Windows зарегистрировано приложение-обработчик;
- внутренние папки Nook, которые содержат другие плитки.

Добавляйте элементы через кнопку **«+ Плитка»**, контекстное меню рабочей области или пункт **«Добавить плитку вручную»** в настройках. В редакторе плитки можно изменить её название и путь, выбрать файл или папку и задать пользовательский значок.

Категории можно создавать, переименовывать, удалять и перемещать. Плитки можно редактировать, дублировать, перемещать между категориями, удалять и группировать во вложенных папках. Доступные действия для плитки находятся в её контекстном меню.

### Внешний вид сетки

На вкладке **Оформление** доступны варианты темы и акцентного цвета, эффекты фона, размер и плотность сетки, отступы, непрозрачность окна и плиток, а также показ часов. Можно выбрать готовую плотность сетки или настроить размер и расстояние вручную. Порядок плиток сохраняется для категории и ширины окна.

## Поиск и управление с клавиатуры

Поле **«Глобальный поиск»** ищет приложения и файлы Windows. Результаты поступают из индекса Windows Search и списка приложений меню «Пуск»; по индексу Windows Search могут находиться не все файлы компьютера.

- Начните вводить запрос в поле поиска.
- Нажмите **стрелку вниз** или **стрелку вверх**, чтобы перейти из поля поиска к результатам.
- Используйте **←**, **→**, **↑** и **↓** для перемещения между видимыми плитками. Направление выбирает ближайшую плитку по её положению на экране.
- Нажмите **Enter**, чтобы открыть сфокусированную плитку. Если фокус находится в поле глобального поиска, **Enter** открывает первый результат.
- Нажмите **Esc**, чтобы вернуться из вложенной папки, выйти из режима редактирования, закрыть настройки или скрыть окно.
- Клавиши **1–9** переключают на соответствующую категорию, когда окно не в режиме редактирования и панель настроек закрыта.

Обычный запуск плитки может скрывать окно Nook, если включена настройка **«Скрывать после запуска плитки»**.

## Профили раскладки

Профили находятся в **Настройки → Другое**. По умолчанию конфигурация получает профиль **«По умолчанию»**.

1. Нажмите **«Создать»** и задайте имя профиля. Новый профиль создаётся на основе текущей раскладки и оформления.
2. Выберите профиль в списке, чтобы переключиться.
3. Используйте кнопки **«Переименовать»** и **«Удалить профиль»** для управления профилями. Последний профиль удалить нельзя.

В профиль входят категории, плитки, вложенные папки, их порядок и параметры сетки по категориям, а также тема, цвет, эффекты фона, размеры окна и плиток, прозрачность, показ часов и анимации. Горячая клавиша, скрытие окна при потере фокуса, скрытие после запуска и автозапуск Windows общие для всех профилей.

Изменения выбранного профиля автоматически сохраняются в локальной конфигурации. Профили также включаются в экспортируемую резервную копию.

## Проверка и восстановление путей

Откройте **Настройки → Другое → Проверить и исправить недоступные пути**. Nook проверит локальные файлы и папки во всех категориях и вложенных папках. Для каждого отсутствующего пути можно открыть редактор плитки и выбрать новое расположение. URI и веб-ссылки не проверяются как локальные файлы: приложение не может подтвердить наличие внешнего обработчика.

Проверить отдельную плитку можно через её контекстное меню → **«Проверить доступность»**. Исправить путь отдельной плитки можно через **«Изменить название / исправить путь...»**.

## Настройки и системный трей

В настройках доступны три раздела:

- **Оформление** — темы, акцентный цвет, эффекты фона, сетка, размер и непрозрачность плиток, показ часов.
- **Основные** — глобальная горячая клавиша, скрытие окна при потере фокуса и после запуска плитки, плавные анимации и запуск вместе с Windows.
- **Другое** — профили раскладки, управление плитками и категориями, проверка путей, папка конфигурации, перезагрузка, импорт/экспорт и сброс оформления.

Nook можно открыть или скрыть двойным щелчком по значку в трее либо назначенной глобальной горячей клавишей (по умолчанию **Ctrl + Alt + Space**). Значок в трее также содержит команды открытия, настроек, режима редактирования, перезагрузки конфигурации и выхода.

## Данные, резервное копирование и восстановление

Конфигурация хранится локально:

```text
%LocalAppData%\Nook\config.json
```

Для текущего пользователя это обычно `%USERPROFILE%\AppData\Local\Nook\config.json`. Конфигурация содержит настройки приложения, категории и плитки, пути к элементам и иконкам, параметры сетки, профили раскладки и выбранный профиль. Само приложение не копирует добавленные файлы в папку Nook: плитки ссылаются на исходные расположения.

### Резервная копия

В **Настройки → Другое** нажмите **«Экспортировать резервную копию...»** и выберите, куда сохранить JSON-файл. Храните резервную копию отдельно от папки приложения, например на другом диске или в пользовательском резервном хранилище.

### Восстановление или перенос

Нажмите **«Импортировать резервную копию...»** и выберите ранее экспортированный файл. Импорт заменяет текущую конфигурацию и перед заменой сохраняет копию действующего `config.json` в папке данных Nook. Внешние приложения и файлы на новом компьютере должны находиться по путям, указанным в плитках; недоступные пути можно исправить встроенной проверкой.

Команда **«Перезагрузить config.json»** повторно загружает конфигурацию с диска и полезна, если файл был изменён вручную. Перед ручным изменением рекомендуется сделать копию файла.

## Установка и требования

- Windows 10 или Windows 11, x64.
- Установщик релиза включает среду .NET и предназначен для самостоятельного запуска.
- Для поиска по файлам используется индексатор Windows Search. Если индексирование отключено или папка не включена в индекс, глобальный поиск может не вернуть ожидаемые результаты.

Получить готовый установщик можно на странице [GitHub Releases](https://github.com/erray2nova/FastPush/releases), если для версии опубликован релиз.

## Сборка из исходного кода

### Обычная сборка

Установите .NET 10 SDK, клонируйте репозиторий и выполните в PowerShell из его корневой папки:

```powershell
git clone https://github.com/erray2nova/FastPush.git
Set-Location .\FastPush
dotnet restore .\FastPush.csproj
dotnet build .\FastPush.csproj --configuration Release
```

Проект использует WPF и целевую платформу `net10.0-windows`. Для запуска и сборки требуется Windows. Зависимости NuGet восстанавливаются через `dotnet restore`.

### Сборка установщика Windows x64

Для формирования установщика дополнительно установите Inno Setup 6 или 7. Затем запустите:

```powershell
.\installer\build-installer.ps1
```

Скрипт публикует приложение как самостоятельный однофайловый пакет для `win-x64`, собирает установщик и удаляет промежуточную папку публикации. Итоговый файл:

```text
artifacts\installer\output\Nook-Setup-v1.1-x64.exe
```

Если установщик не нужен, Inno Setup устанавливать не требуется — используйте обычную сборку `dotnet build`.

## Версии и история изменений

Текущая версия — **1.1.0** (в интерфейсе — **v1.1**). По принятому для проекта правилу каждое следующее изменение приложения увеличивает версию на **0.1**: например, следующее изменение после `1.1.0` получает `1.2.0`. Версия должна быть согласована в метаданных проекта, установщике, его имени и отображаемом интерфейсе.

Каждое логически завершённое изменение сопровождается отдельным Git-коммитом. Это сохраняет понятную историю и позволяет отменить выбранное изменение без удаления более поздней истории:

```powershell
git log --oneline
git revert <хеш-коммита>
```

`git revert` создаёт новый коммит, отменяющий изменения указанного коммита. Это предпочтительнее переписывания общей истории. Git хранит историю исходного кода, но не заменяет резервные копии пользовательского `config.json`; пользовательские настройки следует сохранять отдельно.

## Устройство проекта

- `App.xaml`, `App.xaml.cs` — запуск приложения и общие ресурсы WPF.
- `MainWindow.xaml`, `MainWindow.xaml.cs` — окно лаунчера, плитки, категории, поиск, системный трей, настройки и профили.
- `AppConfig.cs` — модели конфигурации, профилей и представления плиток.
- `RenameWindow.xaml`, `RenameWindow.xaml.cs` — диалог редактирования названий и путей.
- `WindowsIndexedSearchService.cs` — поиск через индекс Windows Search.
- `StartMenuSearchService.cs` — индекс приложений меню «Пуск» и сопоставление поисковых запросов.
- `FastPush.csproj` — целевая платформа, зависимости и версия приложения.
- `installer\Nook.iss`, `installer\build-installer.ps1` — сценарии создания Windows-установщика.

## Решение проблем

### Поиск ничего не находит

Убедитесь, что Windows Search включён и нужные расположения индексируются Windows. Попробуйте найти приложение, которое есть в меню «Пуск». Поиск не гарантирует обнаружение файлов за пределами индексированных расположений.

### Плитка не запускается

Откройте контекстное меню плитки и выберите **«Проверить доступность»**. Если путь больше не существует, воспользуйтесь общей проверкой путей или **«Изменить название / исправить путь...»**. Для URI проверьте, что в Windows установлено приложение-обработчик.

### Горячая клавиша не регистрируется

Сочетание клавиш может быть занято другой программой. Выберите другое сочетание в **Настройки → Основные**. Nook покажет предупреждение, если зарегистрировать комбинацию не удалось.

### Конфигурация повреждена или изменения не применились

Если имеется резервная копия, импортируйте её через **Настройки → Другое**. Перед импортом текущая конфигурация копируется в папку `%LocalAppData%\Nook`. Если `config.json` редактировался вручную, проверьте корректность JSON или перезагрузите его после исправления.

### Как отменить изменение программы

Найдите соответствующий коммит командой `git log --oneline` и выполните `git revert <хеш-коммита>`. Для пользовательских категорий, путей и оформления используйте резервную копию конфигурации — Git не включает файлы из `%LocalAppData%`.
